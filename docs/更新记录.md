# 更新记录

每一版改了什么，新的在上面。文中「见下面某节」「见使用说明」指的是 `docs/开发笔记.md` 里的对应小节；AI 各节在 `ai/BEHAVIOR_PLAN.md`。

## 0.8.0（2026-11-16）

用户定「行为生效、像真人、结果不变差就可以开」，把七个做好但没开的电脑 AI 功能并进现有模块（启动器不加新勾选）：「城下迎击」加守城迎击（优先打攻城兵器、城被围时不急着进城）、渡江迎击、半渡而击、水战守港（第 1.1 版：预计都吃亏不去、兵不到敌军一半不去）；「会战协同」加贴敌待命改还手；「集结齐进」加攻城落单不单打；「攻城评估」加攻城凑够才出。同时删掉五个没用的试验功能的代码：攻城出兵编成、攻城分兵、城下反击、援军断粮、攻城时守港口（特征码清单少了 `siege_min_a`–`e` 五条）。记录在 `ai/BEHAVIOR_PLAN.md` 第五十节。

## 0.7.1（2026-11-15）

「城下迎击」并入「援军继续守」（`ai/BEHAVIOR_PLAN.md` 第四十八节，DLL 功能 `relief`）：迎击完回城的援军，附近另一座自家城还有敌军攻势以它为目标赶来时不回城，能打就去打来敌，打不过就进那座城加强守备，不再「回到家又被派回来」。两局冒烟留下 8 次，守的城一座没丢。水战：「水战守港」（`navaldef`）加「渡江迎击」A/B 六局，守方出手多了，但攻城军势靠港时港照样丢（70% 对 68%），不进默认；港口多半是被没人守时踩掉的（第四十七节，`ai/research/port_flips.py`）。

## 0.7.0（2026-11-15）

「攻城评估」加攻城准备两层（`ai/BEHAVIOR_PLAN.md` 第四十六节）：攻城军势到城外 7–10 格先停下，派兵少的近战部队踩城周没人守的敌方府，府易主、后队到齐再一起攻城（DLL 功能 `fu`、`siegeprep`）；攻城途中每天看粮道，有敌军从身后靠近就派兵够的部队回头打，粮道经过的没人守的敌方府派近处快的部队踩掉（DLL 功能 `supplyguard`）。两轮 A/B：攻城部队溃灭少一成左右，城下断粮 2.1% 降到 0.9%，拿下的城不少。同日又修了攻城部队在城的射程里干等（派去踩府的部队被树带到城下后又被改回去踩府，卡在城边挨打；防断粮也会挑城下的部队去护粮）：射程里站着不打城的掉兵从城下掉兵的 17–21% 降到 9–10%（原版 3–9%），两局攻城部队溃灭 64% → 55%、41%（第四十六节第 1.3 版）。水战只做了测量和伤害公式（第四十七节），没改 AI。启动器改名「[W]三国志14优化启动器」（发布包文件夹和 zip 同名），换新图标（见「图标」），exe 的文件说明修好乱码，使用说明重写成「快速开始 / 功能一览 / 各功能说明 / 常见问题」。启动器加「陷阱」一节「陷阱近身触发」（默认不勾）：陷阱、猛火陷阱、落石要敌军走到陷阱旁 1 格内才发动，效果范围照原版（见下面「陷阱近身触发」）。

## 0.6.0（2026-11-14）

「攻城评估」换成第二版，电脑攻城的出兵门槛算上守方府加成（DLL 功能 `siegefu`）和按实测权重的邻城援军，攒够兵再打（`ai/BEHAVIOR_PLAN.md` 第四十三节、`ai/验收_2026-11-12.md` 最后一节）。启动器加「人力资源管理器」一节：一起加载用户自己的那份人力资源管理器 `dinput8.dll`（游戏目录不放文件，可屏蔽它的命令书按钮，默认屏蔽）；放在 W 文件夹 `第三方Mod\` 下的别人的 Mod 重建时保留、不进 zip。

## 0.5.0（2026-11-14）

启动器加了「电脑 AI」区（试验），八个模块：出兵编成、集结齐进、会战协同、野战撤退、雁行站位、城下迎击、攻城评估、守关，只改电脑势力怎么打（行为树在内存里替换，加 `bin/san14_ai.dll` 每日调整），细节见 `ai/README.md` 和 `ai/验收_2026-11-12.md`。另有自定义府加成、看海时按 Esc 接管；特征码集中到 `sigs/sigs.json`，游戏更新后按功能逐个检查、对不上的单独停用（`tools/sigcheck.py`、`tools/sigfind.py`）。

## 0.4.0（2026-11-11）

跳过报告改在游戏自己的状态线程上、报告流程开始之前完成，回合开头不再有约 2 秒的停顿；「回看报告」也改为在游戏线程里触发。DLL 没注入成功时仍用第 5 版补丁。2026-11-11 实测（全屏 3840×2160）：DLL 挂钩用时不到 1 ms，读档后的报告被跳过、直接进入命令界面（子阶段 2），回看报告 0.02 秒内被游戏接收、弹出原版报告并能正常关闭；推进到下一旬的那次跳过还没出现在日志里，待确认。之后加了和「三国志14 优化伴侣」共存（见使用说明）和自定义府加成，启动器界面重排成「回合报告 / 府加成 / 游戏目录」三段，这些待实测。
